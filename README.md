# Airbnb Clone

A full-stack Airbnb clone web application built using Node.js, Express.js, MongoDB and EJS.

## Features

- User registration and login
- User authentication
- Create and manage property listings
- View property details
- Edit and delete listings
- Reviews and ratings
- Image upload
- Responsive user interface

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- JavaScript

## Installation

1. Clone the repository:
   git clone https://github.com/komaljakhar084/Airbnb_clone.git

2. Install dependencies:
   npm install

3. Create a `.env` file and add your required environment variables.

4. Start the application:
   npm start

## Project Purpose

This project was developed as a major project to demonstrate full-stack web development concepts including backend development, database management, authentication and CRUD operations.
